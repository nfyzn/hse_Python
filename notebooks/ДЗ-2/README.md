# Мониторинг подписки ПРАЙМ

Учебный проект курса «Программирование на Python для бизнес-аналитики»
(ВШБ НИУ ВШЭ, БАЦРФ, 2026/2027).

**Автор:** Михеев Максим Валерьевич

---

## Что здесь

В `notebooks/hw2.ipynb` собрана витрина клиентов сегмента ПРАЙМ: подписки, успешные платежи и участия сведены к одной строке на клиента. Ноутбук считает показатели выручки, тарифов и привлечения, а протокол проверяет число клиентов, сумму денег и число пользователей ПРАЙМ.
